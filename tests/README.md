# Tests

| Directory | Purpose |
|-----------|---------|
| `unit/` | Isolated unit tests (optimization, domain, validators) |
| `integration/` | API, repositories, database |
| `e2e/` | Full allocation and approval workflows |
| `contract/` | OpenAPI schema validation |
| `performance/` | Solver benchmarks for large departments |
| `security/` | Auth and RBAC tests |
| `fixtures/` | Shared test data |

Run: `pytest tests/ -v`
